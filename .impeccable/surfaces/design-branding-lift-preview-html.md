# Lift branding reference

Mode: Experience.

The selected DiamaneOS brand is Lift: three asymmetric folded planes with
softened outer corners. `design/branding/lift/source.json` defines its geometry
and paired colour roles. The preview presents real exported assets, a local
font, responsive download links and a replayable motion study.

Preserve the chosen silhouette and public product name. Lift is the graphic
direction, not a consumer-facing product rename. Use the current brand guide
for clear space, typography and application rules. Keep the initial branding
and Fold alternatives available under `design/branding/archive/`.

Review the SVG exports, local resource loading, theme-matched download links,
320 px layout and reduced-motion cancellation when changing this surface.
The browser motion reference does not establish native boot integration or
device performance. Lumen remains the interface design reference.
