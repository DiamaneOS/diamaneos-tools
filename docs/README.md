# Documentation

The documents of the DiamaneOS build tools, by what you want to do.

| Document | For | What it covers |
| --- | --- | --- |
| [BUILDING.md](BUILDING.md) | Anyone building DiamaneOS | The short path from source to a flashed phone |
| [BUILD.md](BUILD.md) | Builders who need more | Each build step, its checks and records, official and release builds, flashing, troubleshooting |
| [SIGNING.md](SIGNING.md) | Anyone signing builds | Signing with your own keys, factory images, publication checks, the attestation release list |
| [TESTING.md](TESTING.md) | People changing the tools | The test suite and the font, string, overlay and patch checks |
| [SOURCES.md](SOURCES.md) | Maintainers of the source | The manifest, the patch series and upstream tracking |
| [OVERLAYS.md](OVERLAYS.md) | People changing overlays | The resource overlay check |
| [ARCHITECTURE.md](ARCHITECTURE.md) | People changing the tools | Component ownership and the main source decisions |
| [FP6-VENDOR.md](FP6-VENDOR.md) | Fairphone 6 maintainers | The vendor files taken from the stock package, and the device product |
| [FIRMWARE.md](FIRMWARE.md) | Fairphone 6 maintainers | The stock firmware, how it is flashed and updated, rollback rules |
| [FP6-KERNEL.md](FP6-KERNEL.md) | Fairphone 6 maintainers | Building, checking and publishing the kernel set |
| [CARRIER-INTEGRATION.md](CARRIER-INTEGRATION.md) | Fairphone 6 maintainers | Stock carrier data and Wi-Fi calling |
| [TERMS.md](TERMS.md) | Everyone | Short explanations of the terms these documents use |

The [website's build guide](https://diamaneos.de/build/) covers the same build for readers who do
not need the tools' internals.
