# Lift asset exports

SVG masters are generated by `build_assets.py` from `source.json` and the
pinned fonts. Wordmark letters are vector paths, and the images have no remote
resources, embedded scripts or external font requirement.

The two PNG avatars were rendered from the matching SVG masters with Sharp 0.35.4
at 1024 × 1024. To regenerate them with Node.js and Sharp available:

```js
const sharp = require('sharp');
for (const theme of ['light', 'dark']) {
  await sharp(`design/branding/lift/assets/lift-avatar-${theme}.svg`)
    .resize(1024, 1024)
    .png()
    .toFile(`design/branding/lift/assets/lift-avatar-${theme}.png`);
}
```

Run the snippet inside an async function in a CommonJS script. Export other
PNG sizes from the SVG masters rather than upscaling an existing PNG. Preserve
the source aspect ratio; intentional wallpaper cropping is separate from
stretching the mark. The SVG hash manifest excludes raster derivatives.

The archived comparison pages retain the original concept geometry and
applications, with a local font loader and standalone controls added for
offline review. Their suggestions are historical; the Lift reference is the
selected direction.
